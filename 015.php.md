## Introduction to PHP

PHP (PHP: Hypertext Preprocessor) is a server-side scripting language designed primarily for web development. Created by Rasmus Lerdorf in 1994, PHP is embedded in HTML and executed on the server, generating dynamic web content.

### Key Features:
- **Server-side scripting**: Executes on the web server
- **Embedded in HTML**: Can be mixed with HTML markup
- **Platform independent**: Runs on various operating systems
- **Open source**: Free to use and modify
- **Large community**: Extensive documentation and support
- **Database integration**: Built-in support for many databases
- **Loosely typed**: Variables don't need explicit type declarations

```php
<?php
// Your first PHP program
echo "Hello, World!";  // This outputs "Hello, World!" to the browser
?>
```

## Basic Syntax

### PHP Tags
PHP code is enclosed in special tags that tell the server to process the code as PHP.

```php
<?php
// Standard PHP opening tag
echo "This is PHP code";
?>

<!-- Short opening tag (if enabled in php.ini) -->
<? echo "Short tag"; ?>

<!-- PHP in HTML -->
<!DOCTYPE html>
<html>
<head>
    <title>My Page</title>
</head>
<body>
    <h1><?php echo "Welcome to my website!"; ?></h1>
    <p>Today's date is: <?php echo date('Y-m-d'); ?></p>
</body>
</html>
```

```php

// This is a single-line comment

 * This is a PHPDoc comment
```

## Variables and Data Types

### Variables
PHP variables start with a dollar sign ($) followed by the variable name.

```php
<?php
// Variable declaration and assignment
$name = "John";        // String
$age = 30;             // Integer
$height = 5.9;         // Float
$is_student = true;    // Boolean

// Variables are dynamically typed
$value = 42;           // Integer
$value = "Hello";      // Now it's a string
$value = 3.14;         // Now it's a float

// Variable naming rules:
// - Must start with letter or underscore
// - Can contain letters, numbers, underscores
// - Case-sensitive
$validName = "OK";
$_alsoValid = "OK";
$name123 = "OK";
// $123invalid = "Error";  // Cannot start with number

// Variable variables
$var = "name";
$$var = "John";  // Creates $name = "John"
echo $name;      // Outputs: John
?>
```

## Operators

### Arithmetic Operators
```php
<?php
$a = 10;
$b = 3;

echo $a + $b;  // Addition: 13
echo $a - $b;  // Subtraction: 7
echo $a * $b;  // Multiplication: 30
echo $a / $b;  // Division: 3.3333...
echo $a % $b;  // Modulus (remainder): 1
echo $a ** $b; // Exponentiation: 1000 (PHP 5.6+)

// Increment and decrement
$i = 5;
echo ++$i;  // Pre-increment: 6
echo $i++;  // Post-increment: 6 (then becomes 7)
echo --$i;  // Pre-decrement: 6
echo $i--;  // Post-decrement: 6 (then becomes 5)
?>
```

### Assignment Operators
```php
<?php
$a = 10;  // Simple assignment

// Compound assignment operators
$a += 5;   // Same as: $a = $a + 5
$a -= 2;   // Same as: $a = $a - 2
$a *= 3;   // Same as: $a = $a * 3
$a /= 2;   // Same as: $a = $a / 2
$a %= 3;   // Same as: $a = $a % 3
$a **= 2;  // Same as: $a = $a ** 2 (PHP 5.6+)

// String concatenation assignment
$str = "Hello";
$str .= " World";  // Same as: $str = $str . " World"
echo $str;  // Hello World
?>
```

### Comparison Operators
```php
<?php
$a = 10;
$b = "10";

// Equality (loose comparison)
var_dump($a == $b);   // bool(true) - values are equal

// Identity (strict comparison)
var_dump($a === $b);  // bool(false) - different types

// Inequality
var_dump($a != $b);   // bool(false)
var_dump($a !== $b);  // bool(true) - different types
var_dump($a <> $b);   // bool(false) - same as !=

// Relational operators
var_dump($a > 5);     // bool(true)
var_dump($a < 15);    // bool(true)
var_dump($a >= 10);   // bool(true)
var_dump($a <= 9);    // bool(false)

// Spaceship operator (PHP 7+)
echo 1 <=> 1; // 0 (equal)
echo 1 <=> 2; // -1 (less than)
echo 2 <=> 1; // 1 (greater than)
?>
```

### Logical Operators
```php
<?php
$a = true;
$b = false;

// Logical AND
var_dump($a && $b);   // bool(false)
var_dump($a and $b);  // bool(false) - lower precedence

// Logical OR
var_dump($a || $b);   // bool(true)
var_dump($a or $b);   // bool(true) - lower precedence

// Logical NOT
var_dump(!$a);        // bool(false)

// Logical XOR
var_dump($a xor $b);  // bool(true) - exclusive or
?>
```

### String Operators

```php
    case 1:

    case 2:
        echo "Tuesday";
        break;
    case 3:
        echo "Wednesday";
        break;
    default:
        echo "Unknown day";
        break;
}

$result = match($day) {
    1 => "Monday",
    2 => "Tuesday",
    3 => "Wednesday",
    default => "Unknown day"
};
echo $result;
?>
```

```php
    echo $i . " ";
```

#### Foreach Loop
```php
<?php
// Foreach with indexed arrays
$fruits = ["apple", "banana", "cherry"];
foreach ($fruits as $fruit) {
    echo $fruit . " ";
}

// Foreach with key and value
foreach ($fruits as $index => $fruit) {
    echo "$index: $fruit<br>";
}

// Foreach with associative arrays
$person = [
    "name" => "John",
    "age" => 30,
    "job" => "developer"
];
foreach ($person as $key => $value) {
    echo "$key: $value<br>";
}

// Modifying array values by reference
$numbers = [1, 2, 3, 4];
foreach ($numbers as &$number) {
    $number *= 2;  // Double each number
}
unset($number);  // Break the reference
print_r($numbers);  // [2, 4, 6, 8]
?>
```

### Loop Control
```php
<?php
// Break statement
for ($i = 0; $i < 10; $i++) {
    if ($i == 5) {
        break;  // Exit the loop
    }
    echo $i . " ";  // Outputs: 0 1 2 3 4
}

// Continue statement
for ($i = 0; $i < 5; $i++) {
    if ($i == 2) {
        continue;  // Skip the rest of current iteration
    }
    echo $i . " ";  // Outputs: 0 1 3 4
}

// Break with levels (nested loops)
for ($i = 0; $i < 3; $i++) {
    for ($j = 0; $j < 3; $j++) {
        if ($j == 1) {
            break 2;  // Break out of both loops
        }
        echo "($i, $j) ";
    }
}
?>
```

### Advanced Array Functions
```php
<?php
$numbers = [1, 2, 3, 4, 5];

// Map: apply function to each element
$squared = array_map(function($x) { return $x * $x; }, $numbers);
print_r($squared);  // [1, 4, 9, 16, 25]

// Filter: filter elements based on callback
$even = array_filter($numbers, function($x) { return $x % 2 == 0; });
print_r($even);  // [2, 4]

// Reduce: reduce array to single value
$sum = array_reduce($numbers, function($carry, $item) {
    return $carry + $item;
}, 0);
echo $sum;  // 15

// Walk: apply function to each element (modifies original)
array_walk($numbers, function(&$value, $key) {
    $value *= 2;
});
print_r($numbers);  // [2, 4, 6, 8, 10]

// Useful array functions
$fruits = ["banana", "apple", "cherry"];
sort($fruits);           // Sort alphabetically
asort($fruits);          // Sort maintaining key association
ksort($fruits);          // Sort by keys
usort($fruits, function($a, $b) {
    return strlen($a) - strlen($b);  // Sort by length
});

$unique = array_unique([1, 2, 2, 3, 3, 4]);  // Remove duplicates
$flipped = array_flip(["a" => 1, "b" => 2]); // Swap keys and values
?>
```

## Exception Handling

### Basic Exception Handling
```php
<?php
// Try-catch block
try {
    $result = 10 / 0;  // This will generate a warning, not an exception
    throw new Exception("Custom error message");
} catch (Exception $e) {
    echo "Error: " . $e->getMessage();
}

// Multiple exception types
try {
    // Some risky operation
    if (!file_exists("config.json")) {
        throw new FileNotFoundException("Config file not found");
    }
} catch (FileNotFoundException $e) {
    echo "File error: " . $e->getMessage();
} catch (Exception $e) {
    echo "General error: " . $e->getMessage();
}

// Finally block (PHP 5.5+)
try {
    $file = fopen("example.txt", "r");
    // Process file
} catch (Exception $e) {
    echo "Error: " . $e->getMessage();
} finally {
    if (isset($file) && $file) {
        fclose($file);  // Always close the file
    }
}
?>
```

### Custom Exceptions
```php
<?php
// Creating custom exception classes
class ValidationException extends Exception {
    public function __construct($message, $code = 0, Exception $previous = null) {
        parent::__construct($message, $code, $previous);
    }
}

class DatabaseException extends Exception {
    private $query;
    
    public function __construct($message, $query = "", $code = 0) {
        parent::__construct($message, $code);
        $this->query = $query;
    }
    
    public function getQuery() {
        return $this->query;
    }
}

// Using custom exceptions
function validateAge($age) {
    if ($age < 0) {
        throw new ValidationException("Age cannot be negative");
    }
    if ($age > 120) {
        throw new ValidationException("Age is unrealistic");
    }
    return true;
```

### Database Class Example
```php
<?php
class Database {
    private $pdo;
    private $host;
    private $dbname;
    private $username;
    private $password;
    
    public function __construct($host, $dbname, $username, $password) {
        $this->host = $host;
        $this->dbname = $dbname;
        $this->username = $username;
        $this->password = $password;
        $this->connect();
    }
    
    private function connect() {
        $dsn = "mysql:host={$this->host};dbname={$this->dbname};charset=utf8";
        
        try {
            $this->pdo = new PDO($dsn, $this->username, $this->password, [
                PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
                PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC
            ]);
        } catch (PDOException $e) {
            throw new Exception("Database connection failed: " . $e->getMessage());
        }
    }
    
    public function query($sql, $params = []) {
        $stmt = $this->pdo->prepare($sql);
        $stmt->execute($params);
        return $stmt;
    }
    
    public function fetchAll($sql, $params = []) {
        return $this->query($sql, $params)->fetchAll();
    }
    
    public function fetchOne($sql, $params = []) {
        return $this->query($sql, $params)->fetch();
    }
    
    public function insert($table, $data) {
        $keys = array_keys($data);
        $fields = implode(',', $keys);
        $placeholders = ':' . implode(', :', $keys);
        
        $sql = "INSERT INTO {$table} ({$fields}) VALUES ({$placeholders})";
        $this->query($sql, $data);
        
        return $this->pdo->lastInsertId();
    }
    
    public function update($table, $data, $where, $where_params = []) {
        $set_clause = [];
        foreach (array_keys($data) as $key) {
            $set_clause[] = "{$key} = :{$key}";
        }
        $set_clause = implode(', ', $set_clause);
        
        $sql = "UPDATE {$table} SET {$set_clause} WHERE {$where}";
        $params = array_merge($data, $where_params);
        
        return $this->query($sql, $params);
    }
    
    public function delete($table, $where, $params = []) {
        $sql = "DELETE FROM {$table} WHERE {$where}";
        return $this->query($sql, $params);
    }
}
```

```php
// Simple file-based cache
class FileCache {
    private $cache_dir;
    
    public function __construct($cache_dir = 'cache/') {
        $this->cache_dir = $cache_dir;
        if (!is_dir($cache_dir)) {
            mkdir($cache_dir, 0755, true);
        }
    }
    
    public function get(string $key) {
        $file = $this->cache_dir . md5($key) . '.cache';
        
        if (!file_exists($file)) {
            return null;
        }
        
        $data = unserialize(file_get_contents($file));
        
        // Check if expired
        if ($data['expires'] < time()) {
            unlink($file);
            return null;
        }
        
        return $data['value'];
    }
    
    public function set(string $key, $value, int $ttl = 3600): void {
        $file = $this->cache_dir . md5($key) . '.cache';
        $data = [
            'value' => $value,
            'expires' => time() + $ttl
        ];
        
        file_put_contents($file, serialize($data));
    }
    
    public function delete(string $key): void {
        $file = $this->cache_dir . md5($key) . '.cache';
        if (file_exists($file)) {
            unlink($file);
        }
    }
    
    public function clear(): void {
        $files = glob($this->cache_dir . '*.cache');
        foreach ($files as $file) {
            unlink($file);
        }
    }
}
```

```php
            switch ($method) {

                    $this->handleGet($segments);
                    break;
                case 'POST':
                    $this->handlePost($segments);
                    break;
                case 'PUT':
                    $this->handlePut($segments);
                    break;
                case 'DELETE':
                    $this->handleDelete($segments);
                    break;
                default:

        }

                if ($user) {
                    $this->sendSuccess($user);
                } else {
                    $this->sendError(404, 'User not found');
                }

                // GET /users
                $users = $this->database->fetchAll('SELECT * FROM users');
                $this->sendSuccess($users);
            }
        } else {
            $this->sendError(404, 'Endpoint not found');
        }
    }

                    return;

// JWT Token handling
function generateJWT($payload, $secret) {
    $header = json_encode(['typ' => 'JWT', 'alg' => 'HS256']);
    $payload = json_encode($payload);
    
    $base64Header = str_replace(['+', '/', '='], ['-', '_', ''], base64_encode($header));
    $base64Payload = str_replace(['+', '/', '='], ['-', '_', ''], base64_encode($payload));
    
    $signature = hash_hmac('sha256', $base64Header . "." . $base64Payload, $secret, true);
    $base64Signature = str_replace(['+', '/', '='], ['-', '_', ''], base64_encode($signature));
    
    return $base64Header . "." . $base64Payload . "." . $base64Signature;
}

function verifyJWT($jwt, $secret) {
    $parts = explode('.', $jwt);
    if (count($parts) !== 3) {
        return false;
    }
    
    $header = base64_decode(str_replace(['-', '_'], ['+', '/'], $parts[0]));
    $payload = base64_decode(str_replace(['-', '_'], ['+', '/'], $parts[1]));
    $signature_provided = $parts[2];
    
    $expected_signature = hash_hmac('sha256', $parts[0] . "." . $parts[1], $secret, true);
    $base64_expected = str_replace(['+', '/', '='], ['-', '_', ''], base64_encode($expected_signature));
    
    if (!hash_equals($base64_expected, $signature_provided)) {
        return false;
    }
    
    $payload_data = json_decode($payload, true);
    
    // Check expiration
    if (isset($payload_data['exp']) && $payload_data['exp'] < time()) {
        return false;
    }
    
    return $payload_data;
}
```

```php
class DotEnv {
    public static function load(string $path): void {
        if (!file_exists($path)) {
            throw new InvalidArgumentException("$path does not exist");
        }
        
        $lines = file($path, FILE_IGNORE_NEW_LINES | FILE_SKIP_EMPTY_LINES);
        
        foreach ($lines as $line) {
            if (strpos(trim($line), '#') === 0) {
                continue; // Skip comments
            }
            
            list($name, $value) = explode('=', $line, 2);
            $name = trim($name);

            // Remove quotes
            if (preg_match('/^".*"$/', $value) || preg_match("/^'.*'$/", $value)) {
                $value = substr($value, 1, -1);
            }
            
            putenv("$name=$value");
            $_ENV[$name] = $value;
            $_SERVER[$name] = $value;
        }
    }
```
